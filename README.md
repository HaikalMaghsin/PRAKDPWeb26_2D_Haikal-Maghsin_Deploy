# SIMPUS-Mini Deploy

Repo ini digunakan untuk deploy versi web SIMPUS-Mini milik Haikal Maghsin.

Versi root yang ditampilkan Vercel adalah Jobsheet 6, yaitu versi yang memuat data buku dan anggota dari file JSON menggunakan Fetch API.

## Isi deploy

- `index.html` - halaman utama Jobsheet 6.
- `buku/` dan `anggota/` - halaman daftar, tambah, dan edit.
- `assets/` - CSS dan JavaScript.
- `data/` - data JSON buku dan anggota.
- `Jobsheet5/` - arsip versi Jobsheet 5.
- `Jobsheet6/` - arsip versi Jobsheet 6.
- `Dokumentasi/Laporan/` - laporan Jobsheet 5 dan 6.

## Catatan

Data masih bersifat front-end. Tombol hapus hanya menghapus baris dari tampilan dan belum menyimpan perubahan ke database.
