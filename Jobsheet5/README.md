## Hasil penggabungan

- Tujuh halaman SIMPUS-Mini tetap tersedia: beranda, daftar/tambah/edit buku, dan daftar/tambah/edit anggota.
- Tampilan responsif dari Jobsheet 3-4 tetap dipertahankan.
- Hamburger menu sekarang dikendalikan JavaScript melalui tombol `#nav-toggle-btn`.
- Daftar buku dan anggota memiliki kolom pencarian real-time.
- Tombol Hapus menampilkan konfirmasi, lalu menghapus baris dari tampilan.
- Form tambah dan edit mendapat validasi client-side dengan pesan error inline.

## Cara menjalankan

Buka [index.html](index.html) di browser atau gunakan Live Server.

Coba beberapa interaksi berikut:

- Klik hamburger menu pada layar kecil.
- Ketik kata kunci pada daftar buku atau daftar anggota.
- Klik tombol Hapus pada salah satu baris.
- Submit form kosong atau isi tahun/stok dengan nilai tidak valid.

Perubahan data masih bersifat front-end. Baris yang dihapus hanya hilang dari tampilan dan belum tersimpan ke database.
